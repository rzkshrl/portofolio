Konfigurasi Cloudinary

Daftar gratis di cloudinary.com. Buka Settings → Upload → tambahkan Upload Preset baru dengan mode Unsigned. Copy credentials dari Dashboard.

Ada di pojok kiri atas Dashboard
Settings → Upload → Add upload preset → Unsigned

Cara Setup Upload Preset

1. Login ke console.cloudinary.com
2. Klik Settings (⚙️) → tab Upload
3. Scroll ke Upload presets → klik Add upload preset
4. Set Signing mode = Unsigned
5. Di Folder, isi: rsm-portfolio
6. Save. Copy nama preset → paste di field atas.
